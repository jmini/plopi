# Plopi

Temporary publication of the Plopi proof of concept: mini-games for children, no ads, no account.

**Play: https://jmini.github.io/plopi/**

The `gh-pages` branch holds the compiled web app (Kotlin/Wasm + Compose Multiplatform) and is what
GitHub Pages serves. It needs a browser with WebAssembly GC: Safari 18.2+ (iOS 18.2+), Chrome 119+,
Firefox 120+.

To install it on an iPad: open the link in Safari, Share, "Add to Home Screen".
